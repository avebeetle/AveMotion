opacity through the existing compiler, evaluator and stream. It does not enable
the entire Noto Party animation. The installed Avelabs Test Animation EXE stays
unchanged until a separate host delivery is justified and verified.

## Bounded design

Allow at most128 top-level shape items in a shape layer, within the unchanged
asset-wide128-path and256-draw budgets. Other existing limits and per-group
shape/paint/trim grammar remain. Group opacity uses existing transform properties,
evaluation and paint-scope alpha; precomp opacity remains static100. Publication,
stacking and zero-opacity behavior follow independently observed ordinary scenes.

The pinned Telegram reference is commit
`67f103bc8b625f2a4a9e94f1d8c7bd84c5a08d1d` with documented local instrumentation.
`LOTContentGroupItem::update` propagates transform opacity to children;
`LOTFillItem::updateRenderNode` multiplies inherited alpha after byte color
conversion. Group traversal and layer visibility are distinct. These are behavior
checks, not copied code or a new license decision. The group feature does not
change vendor evaluation algorithms or notices. A separately scoped MSVC build
prerequisite below requires additive patch/provenance updates, not relicensing.
